# Redtail analysis — Week 2

This repository contains defensive analysis artifacts for the Redtail botnet samples:
- Reports, YARA rules, Suricata rules, graphs and CSV summaries (safe artifacts only).
- **Raw malware binaries and archives are intentionally excluded** from the repo and stored offline or in a protected location.

See `/rules`, `/iocs.txt`, `/samples_report.csv` for outputs used in writing the blog post.
